# Tide & Tackle

Tide & Tackle is a fully playable browser fishing game built with plain HTML, CSS, and JavaScript. It uses a canvas-rendered fishing scene, procedural fish art, Web Audio sound effects, persistent progression, and a full upgrade loop with rods, bait, locations, and creel upgrades.

## How to run

### Option 1: Open directly

Open `index.html` in a modern browser.

### Option 2: Run a local static server

If you have Python installed:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## How to play

- Hold the action button or the space bar, then release to cast.
- Wait for the bite, or tap lightly while waiting to jig the line and speed things up.
- When the bobber snaps down, hit the action fast to hook the fish.
- During the fight, hold the action to raise the reel band and keep the fish inside it.
- Sell your creel to convert fish into cash.
- Buy rods, bait, bigger creels, and new fishing spots to catch rarer and more valuable fish.

## Progression loop

- Catch fish and sell them for money.
- Gain XP from valuable and well-played catches.
- Level up to unlock stronger gear and deeper locations.
- Build streaks for better catch values.
- Fill out the journal by discovering more species and landing higher-value trophy fish.

## Notes

- Progress saves automatically in browser local storage.
- No external art or audio assets are used.
